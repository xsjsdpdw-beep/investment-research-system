# 周涨跌幅看板

这是一个与“投研体系”完全独立的本地看板，不修改也不依赖投研系统的路由、侧栏、API 或数据。

## 打开

双击 `start.command`，浏览器会自动打开：

`http://127.0.0.1:8787/`

## 数据口径

- 自然周固定为周一至周五。
- 周涨跌幅 = 上周最后一个实际交易日收盘价 → 本周最新实时价/收盘价。
- YTD = 上一自然年最后一个实际交易日收盘价 → 当前最新价/收盘价。
- A 股、港股、美股、日股按各自市场实际交易日取数。
- 2025 年归母净利润实际值、2026/2027 年一致预期来自 `ifind_forecasts.json` 中的 iFind 数据快照。
- PE = 当前总市值 ÷ 对应年度归母净利润，仅在市值币种与利润币种一致时计算。
- iFind 没有返回预测值的公司显示 `—`，不会用其他来源补写。
- 分组和股票增删保存在当前浏览器的本地存储中。
