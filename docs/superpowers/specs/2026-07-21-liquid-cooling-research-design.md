# 液冷行业研究框架与独立网页设计说明

日期：2026-07-21  
状态：待用户审阅  
范围：本轮只交付 Markdown 主文档与独立 HTML 报告；暂不接入投研系统。

## 1. 目标

为具备投研经验、但对液冷产业链尚未形成系统认知的读者，构建一份“先结论、再验证”的行业研究框架。全文遵循“结论—逻辑—信息”三段式，研究内容最终服务于投资判断。文稿需要回答：

1. 液冷行业处于什么阶段，核心驱动是什么；
2. 哪些环节的需求、价值量、壁垒和业绩兑现能力更优；
3. 国内哪些公司值得优先研究，海外龙头与核心客户如何作为对照；
4. 如何用高频和低频数据跟踪行业逻辑，并识别逻辑失效；
5. 如何从商业模式、供需、竞争、财务和估值角度完成公司比较。

## 3. 研究内容结构

### 3.1 第一部分：结论——投资建议

首屏直接给出：

- 行业阶段与核心判断；
- 最值得研究的液冷环节；
- A 股优先跟踪公司与海外对标公司；
- 投资期限、配置优先级和业绩验证窗口；
- 催化剂的时间、传导路径和验证指标；
- 逻辑失效条件、主要风险和降权/退出信号。

“最佳环节”不按单一毛利率排名，而采用可解释的优先级框架：

`研究优先级 = 需求确定性 × 价值量占比 × 技术/认证壁垒 × 国产替代空间 × 盈利弹性 × 财务质量 ÷ 估值压力`

最终将环节分为：核心配置环节、高弹性环节、卡位观察环节。每个重点环节和重点公司都写出“为什么关注”“催化剂是什么”“什么情况下不再关注”。

投资建议页还将增加一张“投资沙盘”：

- Alpha：行业增长、份额提升、产品结构、成本和盈利扩张；
- Beta：景气度、资本开支、政策、市场风格和估值变化；
- 催化剂：事件 → 影响链条 → 业绩/预期变化 → 估值反应；
- 验证条件：需要看到的订单、交付、客户认证、毛利和现金流数据；
- 风险处置：逻辑风险、治理/诚信风险、交易风险和最大风险。

催化剂不再单列为正文后段模块，而是嵌入投资建议、公司卡片和跟踪体系中，避免“研究信息”和“投资动作”脱节。

### 3.2 第二部分：逻辑——为什么这个行业值得投、为什么是这些环节和公司

逻辑部分按从产业本质到公司盈利的顺序展开：

1. 行业投资逻辑：需求驱动、技术演进、功耗密度、政策和资本开支；
2. 基础原理与技术路线：热量、风冷、冷板式、浸没式、CDU、UQD 等；
3. 市场规模与成长空间：全球/中国、数据中心/服务器、冷板/CDU/浸没式等拆分；
4. 产业链全景：上游材料、中游部件与系统、下游应用和价值量；
5. 上游原材料与卡脖子环节：铜铝材料、密封件、冷却液、氟化液及认证；
6. 中游制造工艺：冷板、CDU、管路、快接、泵阀、换热器的工艺、设备、耗材和质量控制；
7. 下游应用：AI 训练、推理、超算、云计算、边缘计算、通信和工业场景；
8. 供需与产能：需求增速、供给扩张、库存、订单、产能利用率和价格压力；
9. 竞争格局：技术路线、客户认证、供应链、产能、份额、议价权和商业模式；
10. 选股逻辑：商业模式、护城河、盈利模型、财务质量和估值压力；
11. 上市公司画像：A 股重点公司、海外对标、业务暴露度、产品位置和竞争优势。

### 3.3 第三部分：信息——用什么数据验证投资逻辑

信息部分围绕“跟踪什么、如何验证、如何比较”展开：

- 跟踪体系：前瞻/同步/滞后指标、数据源、频率、阈值和跟踪输出；
- 产业链与公司数据表：环节、价值量、毛利、壁垒、国产化率和公司映射；
- iFinD 多年财务序列：收入、利润率、ROE、研发、经营现金流、周转率和资本开支；
- 上市公司横向/纵向比较：至少 3—5 家横向、尽可能 3—5 年纵向；
- 关键问题清单：公司调研、供应链调研、客户认证、订单和产能验证；
- 来源索引与口径说明：所有关键数据的出处、日期、口径和证据类型。

各模块统一采用：本节结论 → 逻辑链条 → 支撑信息 → 验证指标。结论层只保留投资相关判断，基础知识和数据表放在逻辑、信息层承接。

## 4. 数据与证据口径

### 4.1 数据分类

正文对事实、预测和判断做明确区分：

- 事实：公司公告、年报/季报、官方技术资料、OCP/NVIDIA 标准、交易所/监管披露；
- 预测：券商、TrendForce、IDC、信通院、产业数据库等机构预测；
- 判断：基于事实与预测推导出的研究结论，必须写出推导链条。

### 4.2 来源优先级

监管披露/公司公告/标准与官方技术资料 > 产业机构与行业数据库 > 券商报告 > 媒体和二手资料。

涉及市场规模、渗透率、价值量、国产化率和客户认证的核心数字，尽量采用两个以上独立来源；无法交叉验证的数字标注“单一来源”。

### 4.3 时间与财务口径

- 优先使用截至 2026-07-21 已公开的资料；原始 v2 的 2026-06-30 口径保留并标记为历史基线；
- 财务比较优先使用 iFinD 多年序列；统一报告期、币种、单位、会计口径和上市公司/海外公司口径；
- 重点展示收入、毛利率、净利率、ROE、研发费用率、经营现金流、应收账款周转率、存货周转率、资本开支和客户集中度；
- 公司未单独披露液冷收入时标注“未披露”，不得以整家公司收入替代液冷收入；
- 若当前环境无法直接调用 iFinD，则使用公司公告/年报和公开市场数据补齐，同时明确数据来源，不把估算写成 iFinD 数据；
- 估值以相对估值和盈利驱动为主；缺乏可比口径时不输出虚假的精确目标价。

## 5. 页面与信息图设计

### 5.1 页面结构

- 结论首页：投资建议、最佳环节、重点公司、催化剂、验证条件和风险；
- 逻辑章节：从基础原理、市场空间、产业链、商业模式、竞争格局到公司盈利；
- 信息章节：跟踪体系、财务序列、公司对比、问题清单和来源索引；
- 章节导航：固定锚点，便于从结论跳到逻辑和信息证据；
- 来源抽屉：点击图表或结论可查看来源、日期、口径和证据类型；
- 打印状态：去掉交互控件和背景动效，保留完整表格与来源。

### 5.2 核心信息图

不使用 Markdown ASCII 图，采用可缩放 SVG/HTML 图形：

1. 热流路径图：芯片 → 冷板/UQD → Manifold → CDU → 设施侧换热；
2. 产业链价值地图：价值量、毛利、壁垒和国产替代空间四维表达；
3. 液冷渗透率与功耗曲线：功耗、机柜密度、渗透率和事件时间轴；
4. 公司竞争矩阵：业绩可见度 × 技术/认证壁垒，气泡大小代表液冷暴露度；
5. 冷板/CDU 工艺图：材料、加工、清洗/钎焊、测试、认证、交付；
6. 跟踪指标仪表盘：前瞻、同步、滞后指标与预警阈值；
7. 财务对比：公司切换、年度序列、横向比较和口径说明。

### 5.3 视觉语言

视觉主题为“Thermal Cartography / 热流地图”：

- 深海军蓝 `#071522`：背景和信息纵深；
- 铜橙 `#F2783F`：热端、增长和重点结论；
- 冰蓝 `#72CFFF`：冷端、效率和设施侧；
- 雾灰 `#A9B7C5`：辅助信息；
- 莓红 `#F05A67`：风险与逻辑失效。

标题使用中文衬线字体栈，正文使用高可读性中文黑体，数字和指标标签使用等宽字体栈。唯一的视觉记忆点是贯穿页面的“thermal ribbon”，表达热量被带走和价值沿产业链传导。

动画只用于热流路径和首屏进入，遵循 `prefers-reduced-motion`；移动端、键盘焦点和打印版均需可用。

## 6. 结构化内容模型

HTML 页面由结构化内容驱动，建议包含：

- `metadata`：版本、数据截止日、覆盖范围、免责声明；
- `thesis`：核心结论、投资建议、最佳环节、重点公司、催化剂、验证条件和失效条件；
- `segments`：环节、价值量、壁垒、国产化、公司和来源；
- `companies`：产品位置、客户/认证、业务模式、财务、验证点和风险；
- `metrics`：指标、数据源、频率、先导属性、阈值和影响；
- `charts`：图表数据、单位、情景、来源和注释；
- `catalysts`：挂接在投资建议与跟踪体系中的时间、事件、影响路径和验证指标；
- `risks`：风险类型、触发条件、观察指标和应对；
- `questions`：公司、供应链和行业调研问题；
- `sources`：来源标题、机构、日期、链接/文件、证据类型和支撑段落。

## 7. 验收标准

### 7.1 研究质量

- 首屏直接出现行业阶段、最佳环节、重点公司和逻辑失效条件；
- 原始 10 个模块全部保留，且补齐供需、商业模式、财务、估值、催化剂和风险；
- 重要数字注明日期、单位、口径和来源；
- 事实、预测和判断明确区分；
- 关键公司至少完成 3—5 家横向比较，尽可能完成 3—5 年纵向财务观察；
- 重点结论存在可追踪的验证指标和证伪条件；
- 不使用无法解释来源的精确数字。

### 7.2 交付质量

- Markdown 可直接阅读和继续编辑；
- HTML 可脱离后端独立打开；
- Markdown、HTML 的核心结论、图表和公司口径一致；
- 图表不使用 ASCII 流程图；
- 页面支持章节导航、来源查看和打印；
- 前端资源加载无外部强依赖，图表在无网络环境下仍能显示；
- 最终交付包含免责声明、来源索引和数据截止日。
